TATTOO TRY-ON V2 — установка патча

1. В GitHub открой репозиторий:
   live495-byte/tattoo-tryon-3d

2. Удали/замени файл realistic-3d.js на файл из этого архива.

3. Обязательно переименуй:
   index..html
   в
   index.html

4. Папку models пока не трогай.
   Новый код сначала ищет:
     models/male-v2.glb
     models/female-v2.glb
   Если их нет — автоматически использует старые:
     models/male.glb
     models/female.glb

5. Что исправлено:
   - загрузка PNG/JPG/WebP;
   - корректное сообщение, если эскиз загружен, но точка тела не выбрана;
   - raycast по ВСЕМ skin mesh, а не только по одному крупнейшему;
   - сглаживание нормалей и отключение flat shading;
   - менее пластиковый материал кожи;
   - мужская/женская модель визуально различаются даже на старых GLB;
   - автоматическая поддержка будущих male-v2.glb/female-v2.glb;
   - более надёжная decal-проекция;
   - клики по разным частям тела;
   - защита от файлов неподдерживаемого типа и >20 МБ.

6. После Commit:
   Settings -> Pages -> Deploy from a branch -> main -> /(root)

7. Для принудительного rebuild можно оставить в index.html:
   <!-- rebuild-pages-v2 -->
