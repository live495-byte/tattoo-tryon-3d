TATTOO TRY-ON V10 — оригинальная мужская Blender-модель

Эта версия сделана напрямую из:
Human Base Meshes v1.4.1 → Body Male - Realistic

ВАЖНО:
V10 больше не использует STL-remesh для тела.

Исправлено:
- нормальное мужское лицо;
- уши из оригинальной модели;
- отдельные пальцы и нормальные кисти;
- добавлены глазные сферы вместо пустых глазниц;
- сохранена UV-развёртка оригинального Blender asset;
- сохранены оригинальные smooth normals;
- убраны разрушительные сглаживания/remesh;
- мужская модель теперь male-v10.glb;
- новый URL версии исключает старый кэш.

Установка:

1. Откройте в GitHub папку:
   models

2. Загрузите:
   male-v10.glb

3. В корне репозитория замените:
   realistic-3d.js

4. female-v2.glb НЕ менять.

5. Нажмите Commit changes.

6. Подождите 1–3 минуты.

7. На странице нажмите:
   Ctrl + Shift + R

После загрузки должно появиться:
"Мужская модель готова: male-v10.glb"

Старые male-v3 / male-v4 / male-v7 / male-v8 можно потом удалить,
но для запуска V10 это необязательно.
