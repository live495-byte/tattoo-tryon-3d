РЕАЛИСТИЧНАЯ 3D-ПРИМЕРКА ТАТУИРОВКИ

Установка
1. Загрузите всю папку tattoo-tryon-realistic-3d на хостинг, сохранив структуру.
2. Открывайте файл tattoo-tryon-realistic-3d.html через сайт (HTTP/HTTPS), а не file://.
3. Не переносите male.glb и female.glb из папки models: HTML использует относительные пути.
4. Сайт должен разрешать загрузку Three.js с cdn.jsdelivr.net.

Состав
- tattoo-tryon-realistic-3d.html — интерфейс;
- realistic-3d.js — 3D-логика и decal-проекция;
- models/male.glb — реалистичная мужская модель;
- models/female.glb — реалистичная женская модель;
- models/MODEL-LICENSE.txt — сведения о лицензии моделей.

Управление
- один палец или левая кнопка мыши: вращение;
- два пальца или колесо мыши: приближение;
- короткое нажатие по коже: точное место нанесения;
- выбор области: автоматическое приближение камеры;
- «Вокруг тела»: изменение положения проекции по окружности;
- «Обхват поверхности»: ширина и глубина decal-проекции.

Ограничение прототипа
Decal-проекция хорошо подходит для небольших и средних татуировок, плеча,
предплечья и частичного обхвата. Полный рукав 360° без шва потребует отдельного
редактора UV-развёртки и подготовки изображения рукава под развёртку модели.
