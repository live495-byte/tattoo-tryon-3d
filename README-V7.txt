TATTOO TRY-ON V7 — новая мужская модель

Эта версия пересобрана заново из исходного STL.
Предыдущие male-v3/male-v4 больше не использовать.

Что сделать:

1. В GitHub откройте папку:
   models

2. Загрузите туда:
   male-v7.glb

3. В корне репозитория замените:
   realistic-3d.js

4. female-v2.glb НЕ менять.

5. Нажмите Commit changes.

6. Подождите 1–3 минуты.

7. Обновите страницу:
   Ctrl + Shift + R

После загрузки должно появиться:
"Мужская модель готова: male-v7.glb"

Новая модель:
- нормальная вертикальная ориентация;
- отдельная мужская анатомия;
- гладкая поверхность;
- цельная сетка без игл и ступеней;
- примерно 721 тыс. треугольников;
- около 12.4 МБ;
- подходит для DecalGeometry и перемещения татуировки.
